# Python Timer App

A desktop timer application built using Python, Tkinter, and Pygame.

## Features
- Simple GUI using Tkinter
- Custom timer input (hours, minutes, seconds)
- Alarm sound notification
- Multithreading support for smooth GUI performance
- Real-time timer tracking

## Technologies Used
- Python
- Tkinter
- Pygame
- Threading
